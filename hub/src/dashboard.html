Easy ArtNet Hub

Interface local. O browser fala com localhost; o hub descobre a placa na rede de iluminação.

Suportado: mesma rede de iluminação, sem client isolation. O hub tenta mDNS service, beacon UDP 6456 e scan da sub-rede; o IP manual é o último recurso. Guest Wi-Fi, client isolation e VLAN sem routing não são suportados.
